# Creative redesign update

This version refreshes the portfolio with a midnight / ultraviolet / electric-aqua visual direction.

## What changed
- Reworked the visual system: deep navy surfaces, violet-to-aqua gradients, softer borders, and subtle ambient texture.
- Refined the hero typography and added a floating production-readiness label to the abstract AI visual.
- Upgraded project cards, navigation, buttons, skill chips, experience rows, and the contact panel.
- Added responsive refinements and keyboard-focus styling.
- Updated the font pairing to Space Grotesk + DM Sans.
- Preserved the existing routes, project data, navigation, theme toggle, contact links, and application functionality.

## Apply the update
1. Extract this ZIP.
2. Replace the contents of your local portfolio project with these updated source files (or copy the changed `src` folder and root config files).
3. Run `npm install` if dependencies are not installed.
4. Run `npm run dev` and inspect the site locally.
5. Run `npm run build`.
6. Commit and push the changes to GitHub. Vercel should deploy the new version automatically.

The archive intentionally excludes `.git`, `.vercel`, `.grok`, `node_modules`, local screenshots, and the attached CV PDF. It contains no `.env` files.
